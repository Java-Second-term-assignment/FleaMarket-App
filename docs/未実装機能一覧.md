# 未実装機能一覧

バックエンド（Java）では実装済みだが、フロントエンド（画面・JS）で未実装または未連携の機能をまとめた一覧です。

---

## 1. 取引チャット

| 項目 | 内容 |
|------|------|
| **バックエンド** | `ChatController`: `GET /orders/{orderId}/messages`, `POST /orders/{orderId}/messages` |
| **現状** | 注文詳細画面（`order/detail.html`）にチャットUIがなく、メッセージの送受信ができない |
| **対応** | 注文詳細にチャットエリアを追加し、上記RESTをfetchで呼び出す |

---

## 2. お気に入り

| 項目 | 内容 |
|------|------|
| **バックエンド** | `FavoriteController`: `POST /api/favorites`, `DELETE /api/favorites/{itemId}`, `GET /api/favorites` |
| **現状** | 商品詳細（`product_detail.html`）にお気に入りボタンはあるが、APIを呼んでいない |
| **対応** | ボタンクリックで `/api/favorites` にPOST/DELETEし、状態（お気に入り済みか）を表示 |

---

## 3. プロフィール・プロフィール画像更新

| 項目 | 内容 |
|------|------|
| **バックエンド** | `UserController`: `PATCH /user/me`, `PUT /user/me/profile-image` |
| **現状** | ユーザー設定（`user_settings.html`）にプロフィール編集モーダルと画像アップロードはあるが、送信先が未接続（フォーム送信でAPIを呼んでいない） |
| **対応** | 保存時に `PATCH /user/me` で表示名・自己紹介を送信し、画像変更時は `PUT /user/me/profile-image` を呼ぶ |

---

## 4. ユーザー設定：配送先更新

| 項目 | 内容 |
|------|------|
| **バックエンド** | 配送先更新用の `POST /user/address/update` 等のエンドポイントは**存在しない** |
| **現状** | `user_settings.html` の住所フォームが `th:action="@{/user/address/update}"` を参照している |
| **対応** | バックエンドに配送先更新APIまたはページ用POSTを追加するか、当該フォームを未実装として無効化する |

---

## 5. 管理者：権限付与・剥奪 / ユーザー有効・無効トグル

| 項目 | 内容 |
|------|------|
| **バックエンド** | `AdminPageController`: `POST /admin/users/admin-role`, `POST /admin/users/toggle` |
| **現状** | 管理画面のユーザー一覧（`admin/users.html`）に、管理者権限の付与・剥奪や有効/無効のトグル操作が**ない**（編集・凍結・強制退会・ブラックリスト復帰・削除は実装済み） |
| **対応** | 一覧の「管理者」列や「状態」列に、管理者権限の切り替えボタン・有効/無効トグルを追加し、上記POSTを呼ぶ |

---

## 6. 掲示板への投稿

| 項目 | 内容 |
|------|------|
| **バックエンド** | `BoardController`: `GET /community/boards/{boardId}/posts`, `POST /community/boards/{boardId}/posts`（掲示板＝商品単位の投稿） |
| **現状** | 掲示板詳細（`board_detail.html`）のフォームが `th:action="@{/comments}"`, `@{/comments/reply}"` を参照しており、**バックエンドに該当エンドポイントがない**（データ構造も「投稿＋コメント」と「商品別掲示板」で異なる可能性あり） |
| **対応** | 掲示板の仕様を整理し、フロントを `POST /community/boards/{boardId}/posts` に合わせるか、バックエンドに `/comments` を追加する |

---

## 7. 認証トークンリフレッシュ

| 項目 | 内容 |
|------|------|
| **バックエンド** | `AuthController`: `POST /auth/refresh` |
| **現状** | フロントエンドからリフレッシュが呼ばれておらず、トークン切れ時の自動更新がない |
| **対応** | 401時などに `/auth/refresh` を呼び、新しいトークンで再リクエストする処理をJS側に実装（必要なら） |

---

## 8. 商品画像APIの利用（任意）

| 項目 | 内容 |
|------|------|
| **バックエンド** | `ItemCatalogController`: `GET /api/items/{itemId}/images`, `GET /api/items/{itemId}/thumbnail` |
| **現状** | 商品詳細等ではサーバー描画で画像URLを渡しているため、必ずしもこのRESTは不要 |
| **対応** | SPA化や遅延読み込みで必要になったら、フロントから上記GETを利用する |

---

## 9. カート（参照先なし）

| 項目 | 内容 |
|------|------|
| **バックエンド** | カート用のエンドポイント（`/cart/add` 等）は**存在しない** |
| **現状** | 商品詳細（`product_detail.html`）に「カートに追加」フォームが `th:action="@{/cart/add}"` を参照している |
| **対応** | カート機能を使う場合はバックエンドにカートAPIを追加するか、当該UIを削除/無効化する |

---

## 実装済み（参考）

- **注文一覧・詳細**: `GET /user/orders`, `GET /user/orders/{id}`、各種操作（確定・発送・受取・キャンセル・評価）はフォームまたはJSで連携済み
- **注文作成**: `POST /order/confirm` で注文作成後、詳細へリダイレクト
- **管理者ユーザー管理**: 凍結・強制退会・ブラックリスト復帰・削除・編集（名前・メール）は画面あり
- **管理者商品管理**: 更新・一時停止・再開・強制削除・ブラックリスト復帰・削除は画面あり
- **ユーザー設定の表示**: お気に入り一覧・プロフィール表示は表示のみ実装済み（更新APIは未連携）
