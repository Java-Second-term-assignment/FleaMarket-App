# 実装されていない機能の詳細調査（REST除く）

バックエンド・フロントエンド（Thymeleaf/JS）の観点で、実装が未完了または不整合な機能をまとめた調査です。REST API関連は除外しています。

---

## 1. カート機能（対応済み）

| 項目 | 内容 |
|------|------|
| **フロント** | `product_detail.html` 79行目: `<form th:action="@{/cart/add}" method="post">` |
| **バックエンド** | `CartPageController`, `CartService` で `/cart/add`, `/cart`, `/cart/remove`, `/cart/checkout` を実装済み |
| **補足** | セッション保存、商品ごとに個別注文を作成するチェックアウト |

---

## 2. 商品ページのレビュー投稿（バックエンド未実装）

| 項目 | 内容 |
|------|------|
| **フロント** | `product_detail.html` 137行目: `th:action="@{/product/{id}/review(id=${product.id})}"` |
| **バックエンド** | `/product/{id}/review` のエンドポイントは存在しない |
| **ドメイン** | `ReviewEntity` は `order_id` に紐づく（注文単位の評価のみ）。商品単位のレビューは未サポート |
| **挙動** | ログイン時、フォーム送信で 404 |
| **仕様** | 注文完了後の評価は `OrderPageController` の `/user/orders/{id}/review` で実装済み。商品詳細からの直接レビューは未対応 |

---

## 3. パスワード再設定（処理がスタブ）

| 項目 | 内容 |
|------|------|
| **フロント** | `password_reset_request.html`: メールアドレス入力フォーム → `POST /password-reset-request` |
| **バックエンド** | `AuthPageController.passwordResetRequest()` がメールアドレスを受け取らず、単に `redirect:/password/forgot` するだけ |
| **挙動** | メール送信・トークン生成なし。画面が戻るだけ |
| **必要な実装** | メール送信、リセット用トークン発行、トークン付きURLの `/password/change?token=xxx` 処理など |

---

## 4. パスワード変更（処理がスタブ）

| 項目 | 内容 |
|------|------|
| **フロント** | `password_change.html`: `password`, `confirmPassword` を送信 → `POST /password-change` |
| **バックエンド** | `AuthPageController.passwordChange()` がパラメータを受け取らず、`redirect:/password/change` するだけ |
| **挙動** | パスワードが一切更新されない。画面がリロードされるだけ |
| **補足** | `/password/change`, `/password-change` は認証必須。ログイン中のユーザーが自分のパスワードを変更する想定 |
| **必要な実装** | `password`, `confirmPassword` の受取、検証、DB 更新 |

---

## 5. 通報機能（UIのみ、バックエンド未実装）

| 項目 | 内容 |
|------|------|
| **フロント** | `product_detail.html` 64行目: 通報ボタン（`<button class="icon-btn" title="通報">`） |
| **バックエンド** | `ReportEntity`, `ReportRepository` はあるが、通報用 Controller・Service は存在しない |
| **挙動** | ボタンクリック時の処理がなく、何も起こらない |
| **必要な実装** | 通報用 POST エンドポイント、ReportService、通報モーダル・フォームなど |

---

## 6. 商品レビュー表示（スタブのまま）

| 項目 | 内容 |
|------|------|
| **フロント** | `product_detail.html`: `reviewSummary`, `reviews` を表示 |
| **バックエンド** | `ProductPageController` が `ReviewSummaryStub`、空の `reviews` を渡している |
| **挙動** | 常に評価 0、件数 0、空リスト |
| **補足** | 注文ベースのレビューは `ReviewService` に実装済み。商品詳細への紐づけ・集計ロジックが未実装 |

---

## 7. 実装済み・連携済み（参考）

| 機能 | 備考 |
|------|------|
| 配送先更新 | `UserPageController` の `POST /user/address/update` とフォームが連携済み |
| 管理者：権限付与・剥奪、有効/無効トグル | `admin/users.html` にフォームあり |
| 管理者：商品・ユーザー編集 | `admin.js` のモーダルからフォーム送信で連携済み |
| 違反リストタブ | `AdminDashboardQueryService.getViolationProducts()` とテンプレートで連携済み |

---

## 8. 優先度の目安

| 優先度 | 機能 | 理由 |
|--------|------|------|
| 高 | 商品ページのレビュー | ユーザーが送信すると 404 |
| 中 | パスワード変更 | ログイン中の変更不可 |
| 中 | 通報 | ボタンがあるが機能しない |
| 低 | パスワード再設定 | メール環境が必要で実装コスト高 |
| 低 | 商品レビュー表示 | 表示はスタブのままでも動作する |
